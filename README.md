A tiny Python program that writes one original one-line joke (under 200 characters) to `/output/entry.txt` for the One-Liner Laughs bounty: a setup with a surprise payoff, no wasted words.

The joke: "I tried to pay my rent in exposure, so my landlord exposed me to the street."

## Run it

```sh
python3 main.py
```

Pure Python 3.13 standard library, deterministic: the same line on every run, no network, no randomness. Set `ONE_LINER_OUTPUT` to write somewhere other than `/output/entry.txt`.
